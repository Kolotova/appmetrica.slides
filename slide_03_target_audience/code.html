Сегмент A

Команды роста в РФ

Кто это

Маленькие и средние приложения, обычно 1–3 приложения.

Главный запрос

Быстро запустить аналитику и видеть эффективность рекламы.

Value moment
  • check_circle SDK подключен, события идут
  • check_circle Первый отчет по каналу или воронке
Критерий выбора: скорость запуска
ads_click

Сегмент B

Performance-команды

Кто это

Команды с активной закупкой: игры, подписки, e-commerce, fintech.

Главный запрос

Связать расходы, установки, события и выручку.

Value moment
  • check_circle Postback и revenue events
  • check_circle Когортный ROAS
Критерий выбора: окупаемость закупки
domain

Сегмент C

Крупные продуктовые компании

Кто это

Экосистемы, банки, телеком, крупные приложения с BI/DWH.

Главный запрос

Надежные данные для продукта, маркетинга и управленческой отчетности.

Value moment
  • check_circle Экспорт данных и модель событий
  • check_circle BI-дашборды и несколько ролей
Критерий выбора: надежность данных

Почему это важно?

Внутри одного рынка разные роли выбирают сервис по разным критериям: скорость, окупаемость и/или надежность данных.
